# Backend

This folder contains the Django REST API and admin dashboard for the smart waste management MVP.

## What lives here

- `config/` for Django project settings and shared routing
- `apps/users/` for authentication and user profile logic
- `apps/reports/` for waste reports and confirmations

## Local development

1. Create a virtual environment.
2. Install dependencies from `requirements.txt`.
3. Run migrations.
4. Start the server with `python manage.py runserver`.
